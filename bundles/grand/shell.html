Click an empire marker or choose an atlas beside the Index button. Scroll or pinch to zoom; drag to pan. Return to Galaxy preserves your view. Inside an atlas, its existing region, system, planet and satellite controls remain available.

Connected to the Codex

The dropdown reads the public AtlasEmbed upload log, follows every results page, and finds slugs ending in -stellar-atlas. New uploads appear without rebuilding this file. The latest upload or deletion determines availability; a new empire remains in the dropdown until its map position is assigned.

The published source HTML is fetched anew when opened. Its own rendering code and data run inside the atlas viewer, preserving its features. Refresh checks both the directory and the open map. Discovery also runs every five minutes while this page is visible.

First-pass previews

Five source snapshots are included for offline use or temporary connection failures. The footer always identifies a live source or a bundled preview. A connection failure never silently passes a preview off as current data.
