# Foundry: identify the station by data, not by name

The Foundry (calidor) is now recognised by `"schematic": "foundry"` on its station record, the same
way the Triad (elysian) is recognised by `"schematic": "triad"`. No atlas other than calidor has a
station named `Foundry`, and no other atlas has `schematic: "foundry"`, so other atlases take the
same branches as before.

## Data

- `bundles/calidor/atlas.json`: `"schematic": "foundry"` added to the `data.stations` record named
  `Foundry` (one added line). The `notableSites` entry and the `solarStations.excludeNames` entry
  also contain the name; they are not station records and were left alone.
